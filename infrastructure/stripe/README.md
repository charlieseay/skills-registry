# Stripe official skills

Imported 2026-10-03 from https://github.com/stripe/ai (verified real: official
`stripe` GitHub org, 1852 stars). Relevant since Seaynic Labs LLC has a live
Stripe integration (seayniclabs-store, stdout-site).

- `stripe-best-practices` — integration decisions: dev/test environment
  planning, API selection, Connect, billing/subscriptions, tax, key
  management, webhooks, OAuth.
- `upgrade-stripe` — API/SDK version migration guidance.
- `stripe-docs` — use `stripe docs` CLI instead of fetching docs.stripe.com
  with curl/WebFetch.
